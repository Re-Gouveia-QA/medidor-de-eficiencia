Primary call-to-action button with a hand-drawn wobbly outline, used for form submits, confirmations, and toolbar actions.

```jsx
<Button variant="primary" iconLeft="check">Salvar atividade</Button>
<Button variant="secondary">Cancelar</Button>
<Button variant="danger" iconLeft="trash" size="sm">Excluir</Button>
```

Variants: primary, secondary, ghost, danger. Sizes: sm, md, lg. Supports `loading` and `disabled`.
