Sketchy line icon glyph, used anywhere a small icon is needed (buttons, inputs, alerts, nav).

```jsx
<Icon name="mail" size={18} />
<Icon name="trash" color="var(--accent-red)" />
```

Available names: chevron-down, chevron-right, check, x, plus, minus, search, eye, eye-off, trash, user, mail, lock, calendar, star, bell, alert-triangle, info, arrow-right, edit, clock, tag, filter, home, logout.
Set `rough={false}` for a crisp (non-wobbly) render, e.g. at very small sizes.
