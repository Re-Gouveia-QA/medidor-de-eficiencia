General-purpose content container with a hand-drawn wobbly border, used for activity items, category tiles, and report summaries.

```jsx
<Card title="Estudo" footer={<Button size="sm">Editar</Button>}>2h30 registradas hoje</Card>
```
Use `tilt="left"`/`"right"` sparingly (e.g. every 3rd card) for a hand-placed sketchbook feel.
